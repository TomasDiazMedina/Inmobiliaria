## Diseño Responsive. 
- 2 media queries: 
    - Max-width 768px: Esto se aplica para tablets y celulares, apareciendo el menú hamburguesa, y cambia la disposición de la información a una sola columna.
    - Max-width 1024px: Esto se aplica para notebooks, la disposición de la información cambia mostrándose en dos columnas.
